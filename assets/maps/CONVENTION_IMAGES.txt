BLUEFOX ODYSSEY — CONVENTION DES IMAGES DE MAPS

1nomdelimage.png
  Image de scène ou panorama du biome.
  Utilisée pour le décor lointain et le hublot du Journal.

01.png, 01_1.png, 01_2.png, 02.png…
  Trames de terrain du plateau jouable.
  Une map peut utiliser une ou plusieurs trames.

Le menu Planète, le décor lointain et le hublot utilisent exclusivement
l’image de scène 1nomdelimage. Les trames 01, 01_1, 01_2… restent réservées
à la surface 3D jouable.

Les associations entre scènes, trames et passages sont déclarées dans
map-assets.js. Les noms physiques pourront être remplacés sans modifier
le contrôleur 3D.
CONVENTION DES IMAGES DE BIOMES

Scène / vue caractéristique :
- le nom commence par le numéro naturel de la map, sans zéro obligatoire ;
- il est immédiatement suivi du nom du biome ;
- exemple : 4DésertMagnétique.png ou 4DesertMagnetique.webp.

Plateaux jouables préférentiels :
- le même numéro est écrit sur deux chiffres ;
- chaque plateau porte ensuite _1, _2, _3, etc. ;
- exemples associés à la scène 4 : 04_1.png, 04_2.png, 04_3.webp.

L’association est préférentielle, pas obligatoire :
- une scène peut exister sans plateau ;
- une scène peut utiliser un seul plateau ou plusieurs ;
- un plateau sans scène reste détecté mais n’est pas publié comme map ;
- les formats PNG, JPG, JPEG et WEBP sont acceptés.

Le moteur classe automatiquement les plateaux par numéro de suffixe.
